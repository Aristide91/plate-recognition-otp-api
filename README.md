# 🚗 Plate Recognition & OTP API

🇫🇷 [Version française](README.fr.md)

A **FastAPI** backend prototype for an EV charging-station check-in flow: the user logs in with **Keycloak**, uploads a photo of their vehicle registration document, the API reads the **licence plate and VIN with OCR**, then confirms the user with a **one-time password** sent by SMS or email.

School project from my exchange semester at EPI Digital School (Sousse, Tunisia).

## Features

- **OCR on registration documents** with EasyOCR: extracts the VIN and the licence plate, with regex rules for **French/EU, Tunisian and Moroccan** plate formats and post-processing of common OCR mistakes (`0`↔`O`, `8`↔`B`...).
- **Authentication** delegated to **Keycloak** (OpenID Connect): the API validates the JWT on every protected route.
- **OTP verification** by SMS (**Twilio**) or email (**SMTP**), with a demo mode when no API keys are set.
- **Minimal web front end** (`frontend/`): login → document scan → OTP → done, plus a small admin page.
- **Unit tests** for the OCR parsing and OTP logic.
- Interactive API docs generated by FastAPI (Swagger UI).

## Tech stack

Python 3.10+ · FastAPI · Pydantic Settings · Keycloak · python-jose · EasyOCR / OpenCV · Twilio · SQLite · Docker Compose

## API

| Method | Route | Description |
|---|---|---|
| `GET` | `/api/v1/auth/me` | Current user, from the Keycloak token |
| `POST` | `/api/v1/vehicles/analyze-registration-doc` | Upload an image, returns plate, VIN, country and raw text |
| `POST` | `/api/v1/otp/send-otp` | Send a 6-digit code by SMS or email |
| `POST` | `/api/v1/otp/verify-otp` | Check the code |
| `GET` | `/api/v1/admin/reservations` | List reservations |

## Run it locally

```bash
cp .env.example .env              # then set KEYCLOAK_ADMIN_PASSWORD (and Twilio/SMTP keys if you have them)
docker compose up -d              # starts Keycloak on http://localhost:8080

python -m venv .venv
.venv/bin/pip install -r requirements.txt    # Windows: .venv\Scripts\pip
export KEYCLOAK_ADMIN_PASSWORD=...           # same value as in .env
.venv/bin/python setup_keycloak.py           # creates the realm, clients and a test user
.venv/bin/uvicorn app.main:app --reload      # API on http://localhost:8000/docs
```

Then open `frontend/index.html` in a browser. EasyOCR downloads its models on the first scan, so the first request is slow.

Run the tests:

```bash
python -m unittest discover tests
```

## Known limitations

This is a prototype, not production code:

- OTP codes are kept in memory (in production: Redis with a TTL).
- The admin route is not protected and CORS allows every origin.
- Only Keycloak runs in Docker; the API runs locally.
